# Sistema de Caducidad de Alimentos

Sistema Full Stack para la gestión de productos alimenticios,
fechas de vencimiento y notificaciones.

## Stack

- React Native
- React
- Django
- Django REST Framework
- MySQL
- Firebase Cloud Messaging

## Componentes

- Aplicación móvil Android
- Plataforma web para supermercados
- Backend REST
- Base de datos MySQL
- Sistema de notificaciones
